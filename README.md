# Ali Akhmad Fauzie - Enterprise Power Platform & Dataverse Architect

Enterprise Power Platform & Dynamics 365 Solution Architect specializing in Dataverse-first architecture, C# Plugins, PCF Controls, enterprise ALM, and AI governance.

This repository contains an interactive executive portfolio, live enterprise migration showcase, competency matrix, and Power Platform application demos built with React, Tailwind CSS, and Vite.

## Features

* **Interactive Executive Portfolio**: Comprehensive showcase of professional experience, skills, and strategic capabilities.
* **Live Enterprise Migration Showcase**: Visual case studies and interactive slices demonstrating legacy system migrations to modern, scalable solutions.
* **Competency Matrix**: Detailed breakdown of technical skills, platform proficiencies, and architectural expertise.
* **Power Platform Application Demos**: Interactive demonstrations of end-to-end Power Platform solutions (Power Apps, Power Automate, Power BI).
* **Interview Mode**: A dedicated, distraction-free view tailored for technical interviews, leadership discussions, and deep dives.

## Tech Stack

* **Frontend Framework**: React 19
* **Styling**: Tailwind CSS 4
* **Animations**: Motion
* **Icons**: Lucide React
* **Build Tool**: Vite
* **Language**: TypeScript

## Getting Started

To run this project locally:

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
